# 内置侧栏工作台

工作台内化自 MIT 许可的 `dsh-better-sidebar@0.24.1`，来源为 [omdsh-dev/DSH-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar)。[LICENSE](upstream/LICENSE) 保留原版权声明，[PROVENANCE.md](upstream/PROVENANCE.md) 记录本项目的修改，[upstream-hashes.json](upstream/upstream-hashes.json) 记录原始发布文件的 SHA-256。DSH App 使用这份固定的运行时代码，不再要求另行安装原插件。

`index.mjs` 挂载 Host API、文件上传与下载、ZIP 打包、HTML 预览、目录监听和模型打开文件的推送通道。`upstream/client-factory.mjs` 由 DSH App 的单一客户端模块激活，保留增强文件树、CodeMirror 编辑与保存、Markdown/Mermaid 和 HTML 预览、Git 与本轮 AI 改动、子代理与后台任务和侧边对话，统一显示在右侧悬浮栏。图片、PDF、Office 和终端由 DSH 官方原生组件提供。

编辑器、Mermaid 和其他语言词典分别由 `upstream/client-editor.js`、`client-mermaid.js`、`client-locale.js` 按需加载。右侧栏通过 `ctx.betterSidebar` 接纳扩展内容；注册 tab、文件 viewer、图标、回调、角标和插件设置的公开接口保持兼容。[客户端桥接](../../client/sidebar-bridge.mjs) 提供 `dsh-better-sidebar`、其 `/client`、`/client/service`、`/client/api` 和 `dsh-external/dsh-better-sidebar` 模块名称。已有扩展可继续贡献内容，GitGraph 的独立正式模块和分支入口继续由其本身管理。

`settings.mjs` 将原设置页面的读写投影到 DSH App 配置的 `sidebar` 字段，更新沿用官方 revision，不覆盖余额等其他配置。公开 `/sidebar` 路径和每个会话的客户端布局存储名称保留；本次集成不删除已有工作区、会话、Git 数据或旧布局。由原文件配置迁移的设置可以保留 tab/viewer 启停、任务视图、HTML 选项、编辑器打开方式和扩展自己的设置。

侧栏展开后的起始页是一张悬浮在右上的输出与会话信息卡。对话和工作台共用完整画布：顶栏、背景、滚动区和输入框座位保持全宽，仅消息正文和输入框内部内容在左侧可用空间中居中，为浮卡预留阅读间隔。打开具体内容后展开为右侧悬浮工作栏。新建对话默认保持侧栏隐藏。会话顶栏的无文字列表图标直接切换侧栏显示，按钮选中状态跟随实际可见性；收起后正文与输入框回正，再次点击恢复已打开的内容。仅顶栏保留加号与收起控制，卡片内不再重复这些按钮。加号打开工具选择页，提供文件、变动、任务、侧边聊天、网页预览及原生终端入口。子 Agent、后台任务、模式与团队各显示一条统一的信息行，左侧是类别与线形图标，右侧是实时状态或当前名称；不再另行显示重复的子 Agent 摘要。信息行读取原生投影及状态，保留原生菜单、会话绑定、任务输出与停止操作；分割线使用卡片内部的正常边界。对话与轨迹在 Electron 左上角桌面“…”菜单中切换，浏览器版则使用会话右上角“…”菜单；会话菜单保留日志下载与反馈入口。Electron 顶栏导航固定在窗口左上角，依次为后退、前进、展开/收起左栏、搜索和更多，不随左栏宽度变化。Web profile 没有原生浏览器时，内置网页预览支持 HTTP(S) 与 localhost 地址；限制嵌入的网站可通过预览工具栏在浏览器中打开。工作台、原生标签、文件树、编辑器、预览、差异、任务和菜单统一使用 DSH App 的 Codex 视觉规则，旧插件的自定义及预设皮肤在此布局中停用。展开和收起使用协调的 200ms 动画，调整窗口、拖动、切换会话和减少动态效果偏好均保留即时布局。

新聊天页保留官方鲸鱼 Logo，居中的标题和底部输入卡片采用统一布局。工作区和 Agent 模式位于卡片顶部并共享卡片宽度；项目内标题显示“我们应该在〈项目名〉中做些什么？”，默认工作区或未选择项目时显示“探索未至之境”。选择项目、切换模式、模型选择、权限、附件、语音及草稿仍由原生组件处理。

Side Chat 的“新建”打开独立对话，“历史”搜索和恢复当前主对话下的既有记录，已打开的对话会直接切换。可重命名对话，并通过“引用上下文”添加主对话草稿、选中文本、打开的文件或补充背景；每条引用都可移除。新建对话继承主对话当时的上下文，之后的主对话消息不会自动同步。各个 Side Chat 的未发送草稿与引用独立保留，发送失败时也保留输入。

刷新页面或重新启动客户端后，已打开的 Side Chat 仍绑定原对话，未发送草稿和引用继续保留；已发送的草稿不会再次准备。文件的标题、定位行号和正在查看的路径，以及网页预览地址，也会随所属主对话恢复。关闭标签会清除该标签的恢复记录，Side Chat 的历史和独立草稿仍可通过“历史”重新打开。

回答可复制或加入主对话草稿，加入草稿后仍由用户发送。“转为主对话”从最近一次已完成的回答创建可继续的主对话，并保留原有对话与工具记录；未完成的后续消息不会包含在该副本中。Side Chat 使用主对话的 Agent 和模型配置，完整保留流式回答、思考、工具与子代理展示、停止和断线恢复。

工作台只保留右侧栏。原底部面板不再显示，旧布局中的标签在对应内容可用后恢复到右侧栏，保留文件路径、标题、行号、预览选择及 Side Chat 线程；尚未可用的扩展标签留在恢复队列中。

在“设置 → 常规 → 工作台”启用“允许 Agent 控制侧栏”后，当前会话的 agent 可使用以下工具。原 `sidebar_open` 保持兼容。

| 工具 | 用途 |
| --- | --- |
| `sidebar_open_view` | 在右侧栏打开文件、文件夹、HTTP(S) 网页、DSH resource 或已注册标签；支持文件行号，`placement` 省略或为 `right` |
| `sidebar_get_tabs` | 读取实际标签 ID、类型、位置、激活状态、可用类型、面板显示状态及连接状态 |
| `sidebar_activate_tab` | 切换到指定标签并显示其面板 |
| `sidebar_close_tab` | 关闭指定标签；原生受保护的开始页可通过收起面板隐藏 |
| `sidebar_set_visibility` | 显示或收起右侧栏，保留标签内容 |

例如 `sidebar_open_view({ target: "src/main.ts", line: 20 })` 打开当前会话工作区中的文件，`sidebar_open_view({ target: "git", type: "tab" })` 展示变动视图，`sidebar_open_view({ target: "sidechat", type: "tab", title: "代码审阅", draft: "请审阅当前改动", context: "待核对的证据" })` 暂存可编辑的侧边对话草稿和上下文。`threadId` 可重新打开属于当前会话的既有 Side Chat；打开标签与暂存文本均不会自动发送消息或启动模型请求。工具由执行上下文绑定会话，不接受 agent 提供另一个会话 ID。客户端通过经过官方连接认证的 WebSocket 回传实际状态及执行确认：`applied` 表示客户端已确认，`requested` 表示已发送但尚未确认，`queued` 表示等待该会话的视图连接。断线时的历史快照标记为非实时。`sidebar_get_tabs` 仅返回 Side Chat 的线程 ID 和草稿、上下文待处理状态，不返回草稿正文。

Side Chat 的 `context` 还可使用 `[{ title: "变动", text: "待核对内容", source: "Changes" }]` 传入带标题的引用，最多 20 条、合计 32 KiB；`source` 可省略。这些引用同样只暂存，不自动发送。

内化适配还修正了文件夹根目录和文件行号导航、原生标签激活、会话范围校验、排队命令顺序、多实例页签，以及切换标签或会话时的编辑草稿和侧边对话状态保留。关闭标签或卸载插件时，原生生命周期仍负责释放资源。

工作台偏好位于 **设置 → 通用设置**，由本项目的紧凑设置行、开关和可展开配置呈现。原“侧边卡片”独立导航和品牌版本卡片不再注册；引擎将原偏好资源交给自有界面，继续保留动态 tab/viewer 设置、扩展提供的字段和自定义设置组件。外部配置变化通过官方设置事件刷新，写入沿用原 revision。

聚焦测试在发布的 DSH `0.2.0-rc.2` 上验证模块别名及重载、贡献注册与释放、跨会话打开目标、失败订阅者的隔离、Host 文件读写、父设置投影、路由与 WebSocket 的跨站拒绝、三个懒加载文件的内容及缓存再验证、实际 Cordis 挂载与释放。渲染测试还验证真实 CodeMirror 行号定位，以及原 Side Chat 对话引擎的草稿、引用、历史恢复、失败重试、停止和转为主对话。原生记录和渲染夹具验证完整刷新恢复、同名标签的会话隔离、关闭清理及已消费草稿不重放。测试使用临时工作区及 API 夹具，没有对用户工作区执行提交、文件删除、Side Chat 模型请求或系统应用启动。
