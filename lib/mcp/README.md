# Integrated MCP Host

The Host implementation is a pinned MIT source copy of `dsh-mcp-connector@0.2.63` from [duhu2000/dsh-mcp-connector](https://github.com/duhu2000/dsh-mcp-connector). `upstream/LICENSE` retains its copyright and permission notice; `upstream/provenance.json` records hashes of the published source files before local changes. This directory contains the Host, bundled catalog, three catalog icons and the DingTalk CLI bridge; its former browser app, client plugin, tests and package updater are excluded.

`installMcp(ctx, { mcp })` mounts a Cordis child with the original validated Host configuration. Required services are `tools`, `storageDomain`, `loader`, `workspaceRegistry` and the official `pluginInventory`; Web routes additionally use `webServer`, `webRuntime` and `connection`. An enabled legacy `dsh-mcp-connector` entry retains ownership until restart, so installing DSH App before removing it never creates competing tools or opens its data domain twice.

Connection records, grants, catalog overrides, snapshots, policies, scope bindings and safe tool caches retain the `mcp_connector` version 1 domain and its seven existing tables. Grant journals remain in `$DSH_HOME/storages/mcp_connector_grants_v1`. The `entryPrefix` default remains `mcp`, and provisioning continues to create or update official `@deepseek-ai/dsh-mcp-client` entries. Existing OAuth authorizations, credentials, disabled connections and snapshot history are reused without a data migration.

`POST /dsh-app/mcp/api` accepts `{ method, params }` and retains the original `{ ok, message, detail }` responses. `GET /dsh-app/mcp/events` publishes only event type, sequence and time. The `/mcp-connector/api` and `/mcp-connector/events` aliases remain available. All routes require DSH connection authentication and a loopback or declared trusted Host; browser mutations additionally require an HTTP(S) Origin matching the current Host. The API uses an explicit method whitelist, a 1 MiB JSON body limit and exact routes. Only the three known catalog icon files are served from the legacy asset prefix; the old static app is absent.

Local changes remove the independent settings/sidebar registration and old package update requests, correct the Zod 4 string-map declarations, await storage closure, and redirect the exact managed DingTalk bridge invocation to the vendored bridge while retaining the pinned DWS installer. Custom stdio commands, arguments, environment and working directories are preserved. Version status reports `integrated: true`, `engineVersion: "0.2.63"`, `updateOwner: "dsh-app"` and `updateAvailable: false`; engine updates ship with DSH App.

Focused tests cover restored storage and policies, secret-preserving snapshots with redacted public output, authenticated routes and scoped dispatch, sanitized SSE teardown, nonempty credentials maps, legacy-owner exclusion, bridge assets and the released Cordis child lifecycle. Live OAuth grants and external MCP server availability remain integration checks performed on the deployed profile.
