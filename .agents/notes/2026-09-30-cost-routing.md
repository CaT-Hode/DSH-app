# 按提供商与模型统计费用

费用账本保留旧 `dsh-cost-meter` 的历史数据，独立读取每日、模型和会话汇总。DSH App 的侧栏底部显示当月费用、Token 和预算；详细页面位于 `/dsh-app/cost`，与桌面共用同一后端账本。

ASS 注入的提供商 ID 与价格表中的厂商 ID 不相同。未知路由仍记录调用次数与 Token，但金额显示为未计价；价格不能从模型名称推断。费用页面允许用户为实际提供商和模型保存美元 / 百万 Token 的费率，缓存读取和写入分别计算。新费率仅用于后续调用，历史估算不重写。预算金额使用所选显示货币，账本内部金额始终为美元。

结算只读取 `assistant/message` 或 `assistant/attempt` 中最终报告的用量，同一 Session 的事件序号不会重复计入；新重试产生的新事件仍独立计数。启动不扫描历史会话，不等待网络。

DeepSeek 官方账户余额独立读取 `user/balance`，保留 API 的币种与十进制字符串。服务只解析 `deepseek-official` 路由实际配置的凭据，拒绝第三方端点与共用的第三方凭据引用，禁止 HTTP 重定向。DSH 0.2 通过 `listConfigurableProviders()` 提供认证拥有者的实际配置 entry id，`settings.describe({ redactSecrets: false })` 返回 Host 的当前值；API-key 拥有者仍按其 `apiKeyEnv` 调用凭据服务。配置读取失败不能归类为网络失败，真正的 TLS、DNS 与连接错误仅返回公开错误类别。请求复用 DSH 启动时安装的全局代理，首次读取时发起，并发读取合并，超时与缓存、重试、手动刷新间隔可配置。失败保留同一账户上次成功余额；更换凭据按不可逆指纹隔离缓存。缓存只保存余额、查询时间和指纹，响应不包含指纹或 Key。卸载中断并等待所属请求。
