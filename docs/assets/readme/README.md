The recordings use the installed DSH App 0.3.6 client with DSH 0.2.0-rc.2, in a separate demo `DSH_HOME`. The demo uses the same installed runtime modules, an isolated profile and account configuration, a small sample workspace, a locally prepared user-message event, and a sample note. No personal session or API key is copied. No model message is sent, image generated, task executed or OAuth consent granted during recording.

Playwright captures the interface and operates its actual controls. Frames are encoded with FFmpeg using a shared palette; pauses and playback cadence are intended for demonstration rather than performance measurement. GIFs are 1280 × 800 pixels and loop indefinitely. The text in the client is Simplified Chinese; both README languages use the same recordings.

The generated header is artwork, not an application screenshot. The application's original whale icon remains in `desktop/DSH.svg`; attribution is recorded in [NOTICE.md](../../../NOTICE.md).

Only final media and this note live in this directory. Private authentication descriptors, demo profile files, capture frames and intermediate recording outputs are outside the source repository.
